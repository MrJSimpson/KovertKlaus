## 🛡️ Definition of Done (DoD) Quality Gate
Before an item is marked as **DONE**:
1. **Types & Docs**: 100% typed TypeScript with clean TSDoc comments explaining purpose, parameters, returns, and security.
2. **Empirical Verification**: Automated test suite passes (`npx tsx src/lib/draw.test.ts`, `npx tsx src/lib/email/email.test.ts`).
3. **Build Health**: Next.js Turbopack production build succeeds with 0 errors (`npm run build`).
4. **Multi-Repo Synchronization**: All changes mirrored and tested in `kovertklaus-saas`.
5. **Git Hygiene**: Committed and pushed to feature branch with standard conventional commit message.
